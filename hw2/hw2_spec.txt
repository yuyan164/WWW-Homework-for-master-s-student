➢ DESCRIPTION  
In this assignment, you will build an interactive Typing Trainer  using JavaScript and DOM . The goal 
is to create a professional web application that tracks typing speed  and accuracy, and provides real -time 
visual and auditory feedback s to the user . Your ap plication must support multiple practice modes, 
specifically focusing on a n "Article Mode " feature that converts external JSON text into interactive 
exercises.

2. The typing trainer  display and functions  
  To fulfill the design specifications of the typing trainer, your application must  implement the 
following components:  
2.1 A character/text display area : A central region to show the practice target character or the 
content of the loaded article.   
2.2 Case selectio n button : Controls to toggle between Uppercase, Lowercase, or "Both" (Mixed Case) 
modes.  
2.3 Mode selection button : Buttons to switch between different practice types (Sequential or 
Randomized).  
2.4 Quick -set timer button : Shortcut buttons to instantly set the duration (e.g., 30s, 60s).  
2.5 A custom time input field : An area for users to manually enter a specific practice duration in 

3 
 seconds.  
2.6 Reset button : A button to res et all settings to default . 
2.7 A "Start" button : A primary action button to start the exercise.  
2.8 An "End Early" button : During the exercise, the interface must include an "End Early" button to 
allow users to stop the practice session before the timer expires, as shown in Figure 2. The 
settings buttons below the keyboard (e.g., the Quick -Set Timer button)  must be hidden.  
 
Figure 2. An "End Early" button  during the typing session  
2.9 A virtual keyboard display : A visual representation of the keyboard layout.  
2.10 Auditory feedback : The system is required to play distinct sound effects based on the accuracy 
of each keystroke .
