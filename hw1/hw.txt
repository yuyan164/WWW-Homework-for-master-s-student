Section 2: Body Content 
The main body of the webpage is divided into two distinct sections. Each section must demonstrate 
proficiency in layout management and interactive design. 
 
Body 1: About Me (Personal Introduction) 
This section focuses on the use of Flexbox for proportional layout and alignment. 
⚫ Layout Distribution: The section must be split into two columns with a 2:1 ratio. 
1. The left two-thirds (2/3) should contain your textual self-introduction. 
2. The right one-third (1/3) should be reserved for your profile photo. 
⚫ Alignment:  
1. The Title (About Me) and the Introduction Text must be perfectly centered (both horizontally 
and vertically) within the left 2/3 container. 
2. The Profile Photo must be centered within the right 1/3 container. 
⚫ Image Styling: The profile photo must be rendered as a circular image (technical hint: border-radius: 
50%) with a 1:1 aspect ratio. 
 
Body 2: My Photo (Image Gallery) 
This section evaluates your ability to implement a structured Grid Layout and CSS animations. 
⚫ Grid Arrangement: You must display exactly six photos arranged in a 3-column grid (2 rows and 3 
columns). 
⚫ Image Specifications: 
1. All images must maintain a perfect square shape (1:1 aspect ratio). 
2. Each image must feature rounded corners and a subtle box-shadow for a modern aesthetic. 
⚫ Hover Animations: When a user hovers over an image, it should scale up smoothly (zoom-in effect). 
1. During the hover state, a caption ( photo Name) must transition into view (e.g., sliding up or 
fading in) at the bottom of the image. 
2. Technical Requirement: These effects must be achieved using pure CSS transitions; no 
JavaScript is allowed.
